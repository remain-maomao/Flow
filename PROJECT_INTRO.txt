Flow - 智能专注力管理助手

【一句话介绍】
Flow 是一款桌面小工具，能自动感知你是在工作还是摸鱼，到点了弹出萌萌的表情包提醒你。

【解决的什么问题】
打开电脑想工作，结果不小心刷了半小时 B 站、微博、YouTube。番茄钟总忘开，屏蔽插件又太粗暴。Flow 全自动运行，不需要你任何操作 — 发现你在娱乐时，右下角飘出一个表情包 + 俏皮音效，轻轻提醒你"该回去啦"。

【核心亮点】
1. 零操作，全自动 — 自动识别当前窗口和浏览器标签页，不需要手动切换模式
2. 不烦人 — 用表情包和卡通音效提醒，而不是警告弹窗，让人会心一笑
3. 聪明区分 — 娱乐站的学习频道（比如 YouTube 编程教程）自动识别为工作
4. 全自定义 — 黑名单、白名单、表情包、音效，全都可以自己配置
5. 安静后台 — 最小化到系统托盘，不占屏幕空间

【技术栈】
Kotlin + Compose 桌面框架，Windows 原生 API 窗口监测，Chrome 扩展获取浏览器标签页。
